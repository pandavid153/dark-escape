# Dark Escape

An original, self-contained Godot 4 asymmetric-horror prototype. It does not use Dead by Daylight assets, characters, maps, names, or code.

## Play

1. Play the browser build at https://pandavid153.github.io/dark-escape/.
2. Or open `project.godot` in Godot 4.2 or newer and run the Godot version.
3. Move with `WASD` or arrow keys. Hold `E` or `Space` near an unlit signal fire.
4. Ignite all three signals and reach the glowing gate at the east edge before the hunter downs you.
5. Press `R` after an outcome to restart.

The prototype uses generated vector visuals and needs no imported art or audio files.
